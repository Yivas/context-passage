## A narrow contract with hard boundaries

Context Passage is in its foundation phase. The first milestone covers conversation continuity and
shared MCP declarations between OpenCode and Pi. There is no package to install yet, and the host
versions under investigation are not supported versions.

<CardGrid>
  <Card title="Opt in at every boundary">
    Installation grants no access. A project root, sync direction, historical
    import, and each MCP resource require explicit approval.
  </Card>
  <Card title="Keep sources immutable">
    Synchronization never deletes or rewrites a source session. Retries must be
    idempotent and recoverable after interruption.
  </Card>
  <Card title="Name every fidelity loss">
    Tool calls, permissions, hidden reasoning, branches, and runtime state are
    not treated as equivalent when a destination host cannot represent them.
  </Card>
  <Card title="Leave credentials with the host">
    Shared MCP declarations do not copy tokens, credentials, OAuth state, or
    host-private values.
  </Card>
</CardGrid>
